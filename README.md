# Week 9 Assignment

Five Java solutions for the Week 9 assignment.

## Questions

- `QUESTION 1`: Movie Ticket Counter
- `QUESTION 2`: Parcel Shipping Desk
- `QUESTION 3`: College Fee Counter
- `QUESTION 4`: City Cab Fare Meter
- `QUESTION 5`: Home Appliance Energy Report

Each question folder contains its `.java` source and compiled `.class` file.

## Compile and run

From the relevant question folder, compile and run the matching class. For example:

```text
javac QUESTION1.java
java QUESTION1
```

Use `QUESTION2`, `QUESTION3`, `QUESTION4`, or `QUESTION5` for the other folders. Java 14 or newer is required because the solutions use switch expressions.
